# NIRJHAR Water — website starter

A responsive static website concept for a packaged drinking water brand and its retailer/distributor enquiries.

## Files
- `index.html` — homepage, product range, business supply and enquiry form
- `styles.css` — responsive design and styling
- `app.js` — mobile navigation and local-only enquiry form behaviour
- `privacy.html` — draft privacy notice
- `terms.html` — draft website terms

## Preview locally
Open `index.html` in a modern browser. For a more realistic local preview, use VS Code with Live Server or run a static HTTP server.

## Deploy on Vercel
1. Extract the ZIP.
2. Upload the folder contents to a Git repository (keep the files at the repository root).
3. In Vercel, import that repository.
4. Select **Other** / static site if prompted; no build command is required and the output directory is the project root.
5. Deploy to a preview URL first, test mobile layouts and links, then connect a domain.

## Important before public launch
1. Replace placeholder business contact details and confirm service coverage.
2. Connect the form to a secure backend or approved form service with server-side validation, spam protection, access control, retention/deletion rules and a privacy notice that accurately describes the data flow. The current form does not send or store data; it only prepares text locally.
3. Complete the legal entity details, privacy notice and terms after reviewing actual data flows and current Indian requirements, including the DPDP Act and rules in force at launch.
4. Confirm applicable food safety, packaged drinking water, labelling, testing and other licences/standards with the relevant authorities and qualified compliance adviser. Do not advertise unverified BIS/FSSAI approvals or claims.
5. Check the NIRJHAR trademark and similar marks with an appropriate search and professional advice before printing labels or investing in packaging.
6. Add real product photographs, verified pack sizes, price/order information, delivery coverage, email/phone, and any required licence details.
7. Configure HTTPS, security headers, error monitoring, backups and a documented process for handling privacy requests and incidents.

This is a front-end starter, not a complete e-commerce system or legal compliance certification.
